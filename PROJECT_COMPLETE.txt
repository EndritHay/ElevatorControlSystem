┌──────────────────────────────────────────────────────────────────────────────┐
│  🎨 CUSTOMIZATION EXAMPLES                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

Change elevator count and floors:
  Edit src/App.tsx, line 20:
  initializeElevators(5, 15, 500)  // 5 elevators, 15 floors

Adjust speed:
  initializeElevators(3, 10, 300)  // Faster: 300ms per floor

Change theme colors:
  Edit src/theme/index.ts

Add new language:
  1. Create src/locales/de/translation.json
  2. Import in src/i18n/reactAdapter.ts
  3. Done! Language appears in switcher
